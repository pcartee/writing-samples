Faithful Verification (1)

Download OpenAPI specification:

License: Copyright(C) 2022 Intel Corporation. All Rights Reserved.

The Faithful Verification provides the evidence to verify the integrity of the services involved in the process of attestation. Evidence is created by verifying the quotes provided by services running in the TEE, during their registration process. These measurements provided by individual services are validated against the permitlist configured.

TokenAuditReport

Generates faithful verification token audit report. This report can be attested using the faithful verifier tool to verify the integrity of the services involved in the attestation. This API requires an Attestation API key (apiKeyAuth).
