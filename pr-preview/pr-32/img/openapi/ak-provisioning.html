Attestation Key Provisioning Service (1)

The Attestation Key Provisioning Service (AKPS) is a component of Intel® Trust Authority. It is responsible for issuing Attestation Key Certificate after verifying the EK (Endorsement Key) Certificate to make sure that it is a legitimate TPM (Trusted Platform Module).

GetAKCertificate
