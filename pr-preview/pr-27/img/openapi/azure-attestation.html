The Microsoft Azure Attestation (MAA) Adaptor Service in Intel Trust Authority is designed to support the MAA attestation client. It offers fully compatible interfaces with MAA for both request and response formats.

MaaAttestOpenEnclave

Verifies SgxEnclave evidence and issues an MAA-format attestation token for a successful attestation request. An attestation failure returns an error message. This API requires an attestation API key.
