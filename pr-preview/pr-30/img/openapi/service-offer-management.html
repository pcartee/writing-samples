These set of management APIs supports CRUD operations on tenants, tenant users, and API client keys. Tenant users can subscribe to different service offers like SGX/TDX Attestation under Basic or Premium plan. Once subscribed to a service offer, users can generate the corresponding APIClient key to use attestation services. Tenant users are by default enrolled to Premium plan and have flexibility to switch between plans.
