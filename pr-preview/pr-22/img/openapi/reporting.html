The Reporting Service (reports) is a component responsible for aggregating metrics related to APIs and Amber components

TscAttestationDetails

The Reporting Service fetches a summary of the API attestation requests made by a tenant for a given time frame.

Authorizations:
apiKeyAuth
query Parameters
serialNumber
string

Serial Number of the product for which the metrics need to be fetched.

verdict
string
Enum: "matched" "unmatched" "unknown device" "bad request" "other"

Verdict of the attestation request. Can be matched, unmatched, unknown device, bad request or other.

offset
required
number

offset is the number of records you wish to skip before selecting records. It's value should not be less than 0.

limit
required
string

It is the number of records that need to be fetched for that transaction. It's value should not be less than 0 and maximum value supported is 100.

header Parameters
Accept
required
string
Value: "application/json"

Accept header

Request-Id
string

Request Id
