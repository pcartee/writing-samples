Attestation (1)

Attestation compares workload measurements and configuration against a set of policies. A successful attestation generates a signed token to indicate the workload's compliance. Tenant-associated policies may be indicated in the request. If no policies are indicated, the attestation is performed against policies associated with the API key (not the API client). The enclave measurement is always evaluated against default and user-specified policies.

AttestationToken

The Appraisal API attests to the submitted evidence and policies. A successful verification returns a signed JWT attestation token. An attestation failure returns an error message. This API requires an attestation API key.
